## 产品概要

化妆品品牌 OEM 包装制造。瓶身容器（PET / 玻璃 / 亚克力）+ 瓶盖 + 标签 + 外箱包装，一站完成。

## 容器类型

- **PET 瓶**：30ml / 50ml / 100ml / 200ml / 500ml
- **玻璃瓶**：精油用 5ml 起 / 香水用 30ml 起
- **亚克力罐**：50g / 100g / 200g（面霜用）
- **真空瓶**：30ml / 50ml（高活性配方适用）
- **软管**：30ml–200ml（牙膏、护手霜等）

## 定制能力

- 瓶身颜色（透明 / 着色 / 磨砂）
- 印刷（丝印 / 烫金 / UV 喷墨）
- Logo 浮雕 / 压印
- 专属模具（1,000 件起小批量）

## Amazon / FBA 支持

- FBA 入仓标签预贴
- 多 SKU 套装组装
- 日文 / 英文 / 中文标签支持
- 跨境电商履约对接
