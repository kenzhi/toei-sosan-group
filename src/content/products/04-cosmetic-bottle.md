## 製品概要

化粧品ブランドの OEM パッケージ製造。ボトル容器（PET / ガラス / アクリル）+ キャップ + ラベル + 外装箱まで一貫対応。

## 対応容器

- **PET ボトル**：30ml / 50ml / 100ml / 200ml / 500ml
- **ガラスボトル**：精油用 5ml〜 / 香水用 30ml〜
- **アクリルジャー**：50g / 100g / 200g（クリーム用）
- **エアレスボトル**：30ml / 50ml（高配合処方向け）
- **チューブ**：30ml〜200ml（歯磨き粉、ハンドクリーム等）

## カスタマイズ

- ボトルカラー（透明 / 着色 / フロスト）
- 印刷（シルク / ホットスタンプ / UV インクジェット）
- ロゴエンボス / デボス
- オリジナル金型（小ロット 1,000 個〜）

## Amazon / FBA 対応

- FBA 納品ラベル事前貼付
- セット組立（複数 SKU まとめ）
- 日本語・英語・中国語ラベル対応
- 越境 EC フルフィルメント連携
