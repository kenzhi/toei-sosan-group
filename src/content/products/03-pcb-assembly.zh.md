## 服务概要

从 PCB 贴装（SMT + DIP）到最终组装、检测全流程支持，适合中小批量（100–10,000 件）IoT 设备的试制与量产。

## 工艺流程

1. **元件采购**：基于 BOM 清单，由合作商社统一采购
2. **SMT 贴装**：雅马哈 YSM20 + 富士 NXT III 产线
3. **DIP 焊接**：手插 + 自动插件机
4. **回流焊 / 波峰焊**：无铅工艺
5. **AOI / X 光检测**：贴装质量确认
6. **ICT / FCT**：电气特性测试
7. **最终组装**：外壳组装 + 线缆连接
8. **出货前 QC**：24 小时老化测试

## 贴装能力

- PCB 尺寸：50 × 50 mm – 350 × 250 mm
- 元件尺寸：01005（0.4×0.2mm）起步
- 支持 BGA / QFN / CSP
- 双面贴装 / 多层板（最高 8 层）

## 认证

- ISO 9001
- 支持 IPC-A-610 Class 2 / Class 3
- UL 认证支持（按客户要求）
