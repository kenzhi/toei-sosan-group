## Product Overview

OEM packaging for cosmetic brands. Bottle (PET / glass / acrylic) + cap + label + outer box, all under one roof.

## Container Types

- **PET bottles**: 30 / 50 / 100 / 200 / 500 ml
- **Glass bottles**: 5 ml+ for essential oils, 30 ml+ for perfume
- **Acrylic jars**: 50 / 100 / 200 g (for creams)
- **Airless bottles**: 30 / 50 ml (for sensitive formulations)
- **Tubes**: 30–200 ml (toothpaste, hand cream, etc.)

## Customization

- Bottle color (clear / tinted / frosted)
- Printing (silk / hot stamp / UV inkjet)
- Logo emboss / deboss
- Custom mold (from 1,000 pieces)

## Amazon / FBA Support

- Pre-applied FBA labels
- Multi-SKU bundle assembly
- Japanese / English / Chinese labeling
- Cross-border e-commerce fulfillment integration
