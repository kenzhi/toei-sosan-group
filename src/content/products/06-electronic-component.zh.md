## 服务概要

面向车载电气与工业设备的定制电子元件，覆盖规格制定 + 试制 + 认证获取 + 量产。

## 部件类型

- **各类传感器**：温度 / 压力 / 接近 / 光学
- **连接器 / 线束**：防水（IP67/68），符合车载规格
- **定制 PCB**：小批量支持（10–1,000 件）
- **组装模块**：传感器 + PCB + 外壳

## 认证支持

- **车载**：IATF 16949 合作工厂
- **工业**：CE / UL / RoHS
- **医疗**：ISO 13485 合作工厂
- **防爆**：ATEX / IECEx（可选）

## 开发流程

1. 需求沟通（工程师直接对接）
2. 图纸 + 3D 模型建立
3. 试制（内部样件）
4. 功能评估 + 可靠性测试
5. 认证支持
6. 量产移交
7. 量产后的持续改进
