## サービス概要

車載電装・産業機器向けカスタム電子部品。仕様策定 + 試作 + 認証取得 + 量産を一気通貫で。

## 対応部品

- **各種センサー**：温度 / 圧力 / 近接 / 光学
- **コネクタ / ハーネス**：防水（IP67/68）、車載規格対応
- **カスタム PCB**：小ロット対応（10〜1,000 個）
- **組立モジュール**：センサー + PCB + 筐体

## 認証対応

- **車載**：IATF 16949 対応提携工場
- **産業**：CE / UL / RoHS
- **医療**：ISO 13485 対応提携工場
- **防爆**：ATEX / IECEx（オプション）

## 開発フロー

1. 仕様ヒアリング（技術者が直接対応）
2. 図面 + 3D モデル作成
3. 試作（社内モックアップ）
4. 機能評価 + 信頼性試験
5. 認証取得支援
6. 量産移管
7. 量産後の継続改善
